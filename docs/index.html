Proyecto web full-stack

mi-landing

Landing page de producto con formulario de captura de contactos: frontend en React + Tailwind y API en Express, publicada en GitHub Pages.

  • React
  • Vite
  • Tailwind CSS
  • Express
  • Node.js
  • GitHub Actions
  • GitHub Pages

Qué hace

Página que convierte

Hero, beneficios, planes y un formulario de email en una sola vista.

API mínima y probada

Express con /api/health y /api/contact, que valida el email; 4 pruebas con node --test.

Publicada sola

Cada push construye el frontend y lo publica en GitHub Pages en modo demo.

Entra y sale

Entrada: petición a la API

Lo que envía el formulario:

POST /api/contact
Content-Type: application/json

{"email": "persona@ejemplo.com"}

Salida: respuesta

Email válido o inválido:

201 {"received": true}
400 {"error": "Email inválido"}

Correrlo

cd backend && npm install && npm run dev     # API en :3001
cd frontend && npm install && npm run dev    # http://localhost:5173
